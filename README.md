# Gaussian splat of a swing

Sal Frelick, World Series Game 2, rebuilt in 3D from 8 broadcast cameras. Drag to look around while it plays.

**[Open it](https://sdm-commits.github.io/gaussiansplat/)**

The licence covers the viewer code in `index.html`. It does not cover `swing.bin` and `swing.json`: the scene is derived from broadcast footage, whose rights belong to its owners.
